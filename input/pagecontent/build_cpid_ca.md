<p style="color:#374151; font-size:.94em; line-height:1.7; margin-bottom:16px;">Health Canada asks for a <strong>Certified Product Information Document (CPID)</strong> with quality submissions. It is a condensed summary of the key quality information, reflecting the final data agreed in review, and is the reference Health Canada uses for post-approval inspections and post-approval changes. It is a Canadian Module 1 document, so it sits outside the <a href="build.html#document-granularity" style="color:#2563eb; font-weight:600;">20 Module 2.3 and Module 3.2 templates</a> and does not change them.</p>

<h3 style="font-size:1.35em; font-weight:700; color:#111827; margin-bottom:8px;">Rules</h3>
<ul style="font-size:.88em; color:#374151; line-height:1.8; margin:0 0 20px 0; padding-left:20px;"><li>One CPID document per CPID. A CPID-CE covers all strengths of one dosage form.</li><li>Section titles keep the template's parenthetical identifiers filled in, e.g. "Manufacturer(s) ([drug substance name], [manufacturer])". A Drug Substance or Drug Product section repeats once per drug substance (and manufacturer) or dosage form, told apart by its title.</li><li>Sub-sections sit under their parent's heading code (<code style="font-family:monospace; font-size:.8em; color:#0891b2;">hc-cpid-sec-1</code>). A CPID-CE has exactly one Summary of Product Information section (<code style="font-family:monospace; font-size:.8em; color:#0891b2;">hc-cpid-ce-1</code>), and a CPID-B exactly one Introduction section (<code style="font-family:monospace; font-size:.8em; color:#0891b2;">hc-cpid-b-1</code>).</li><li>A new CPID version references the version it replaces in <code style="font-family:monospace; font-size:.8em; color:#0891b2;">Composition.relatesTo</code>. Annotating the changes since the last approved CPID stays in the narrative, as the Health Canada guidance asks.</li><li>CPIDs are sent with the Canadian Module 1, not in a <a href="StructureDefinition-Bundle-document-collection-pq.html" style="color:#2563eb; font-weight:600;">BundleDocumentCollectionPq</a> of Module 3.2 documents.</li></ul>
